# Keyboard shortcuts

## Navigation
- **Tab** — Move to the next interactive element
- **Shift+Tab** — Move to the previous element
- **Enter / Space** — Activate a button
- **Arrow keys** — Switch between asset type options

## Step indicator
- The step indicator uses `role="navigation"` so screen readers announce it as a landmark
- The active step has `aria-current="step"` so screen readers say "current step"

## Tested with
- macOS VoiceOver: press Cmd+F5 to toggle
- Windows NVDA: free download at nvaccess.org
