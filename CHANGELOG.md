## [0.1.0] - 2025-01-01

### Added
- Initial release
- `TransactionBuilder` React component with 5-step flow
- Support for 23+ Stellar operation types
- In-browser signing with secret key
- External XDR signing (paste signed XDR)
- Transaction submission to Horizon
- `useTransactionState` hook for headless usage
- Full TypeScript types and exports
- Tailwind-based dark theme
- Accessible keyboard navigation
- Demo application
